SOURCES — Audio Cleanup Before/After Demo (Sample project)

Files: media/audio-before.mp3, media/audio-after.mp3 (16 s each).

  • Voice: excerpt from A Few Maxims for the Instruction of the Over-Educated by Oscar Wilde, read by a LibriVox volunteer, from LibriVox "Short Story Collection Vol. 014". LibriVox recordings are in the public domain (https://creativecommons.org/licenses/publicdomain/). Source: https://archive.org/details/short_stories14_librivox
  • The "before" file is not a real client recording: electrical hum (60/180 Hz), low-frequency rumble and high-frequency hiss were added synthetically to the clean public-domain recording to simulate a noisy room.
  • The "after" file is that noisy version processed with high-pass filtering, hum notch filters, and spectral noise reduction, then level-matched.
